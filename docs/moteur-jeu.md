# Moteur de jeu

Ce fichier regroupe les regles communes utilisees par plusieurs ennemis.

## Dés

Les dés peuvent etre lus de deux facons :

- par symbole : blanc, jaune ou rouge ;
- par chiffre : 1, 2, 3, 4, 5 ou 6.

## Suites

Les suites utilisent les chiffres des dés.

### Micro suite

- 1,2,3
- 2,3,4
- 3,4,5
- 4,5,6

### Petite suite

- 1,2,3,4
- 2,3,4,5
- 3,4,5,6

### Grande suite

- 1,2,3,4,5
- 2,3,4,5,6
